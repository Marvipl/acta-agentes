# Acompanhamento

1. Identifique a análise congelada (`projetos/<id>/v<n>`).
2. Acione `calibracao-analise`: para cada insight aprovado, registre com Marcus se a recomendação foi adotada, o resultado medido, a data e a fonte, em `conhecimento/pos_decisao/resultados.csv`.
3. Esse registro calibra a confiança do squad por tipo de insight; ele nunca entra como evidência dentro de outra análise.
4. Promova às bibliotecas o que funcionou: receitas de análise, perfis de especialista, problemas por sistema de origem.
