# Base de conhecimento do squad de análise

| Pasta | Conteúdo | Quando é usada |
|---|---|---|
| `contexto/acta.md` | Contexto da empresa | Sempre |
| `metodologia/rigor.md` | Tipos de análise, níveis, incerteza, barreiras, estados | Plano e análise |
| `decisao/` | Dimensões da prontidão e banco de perguntas-chave | Enquadramento da decisão |
| `receitas/` | Scripts de análise reaproveitáveis | Antes da análise |
| `especialistas/` | Perfis setoriais aprovados | Antes da análise |
| `pre_analise/problemas_por_fonte.csv` | Defeitos conhecidos de cada sistema de origem | Antes da análise |
| `pos_decisao/resultados.csv` | O que aconteceu com as recomendações | Só para calibrar a confiança do squad; nunca como evidência dentro de uma análise |
