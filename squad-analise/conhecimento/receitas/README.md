# Receitas de análise

Scripts de análise que funcionaram, prontos para copiar para `analises/` e adaptar. Cada receita segue a interface `rodar(con, ctx)` de `motor/registro.py`.

| Receita | Para quê |
|---|---|
| `comparacao_grupos.py` | Diferença entre dois grupos com IC, tamanho de efeito e robustez por segmento |
| `tendencia_mensal.py` | Série mensal, tendência com IC e gráfico |

A calibração promove novas receitas a partir de análises aprovadas.
